Fun-CosyVoice3-0.5B-2512
========================

This repository contains an on-device text-to-speech package for Qualcomm NPUs: a prebuilt inference library
(sdk/lib/libcosyvoice3.so) with its C header and Python binding, a Python business layer, Python examples and a web
demo. Application/business code and SDK binaries are separately licensed; see LICENSING.md.

Model files
-----------
The model files (quantized QNN context binaries, host-side tensors and the two voice cloning models) are not
distributed in this repository; they are downloaded separately (see docs/VOICE_CLONING.md#1-prepare-the-environment-and-model-resources) and come with their own license
terms.

Inference runtime
-------------------------
The SDK bundles Qualcomm QNN under the terms in sdk/lib/qnn248/. Aidlux LMS and the device drivers are system dependencies.
They are not part of this repository and are covered by their own licenses.

Voices
------
The built-in voices (sdk/assets/voices/{female-zh,female-en,male-en}/) are cloned from one recording each:
  female-zh  AISHELL-1 (https://www.openslr.org/33/), utterance BAC009S0736W0134, Apache License 2.0
  female-en  LibriSpeech test-clean (https://www.openslr.org/12/), utterance 121-121726-0003 (2.48-6.58 s), CC BY 4.0
             (V. Panayotov, G. Chen, D. Povey, S. Khudanpur, "LibriSpeech: an ASR corpus based on public domain audio
             books", ICASSP 2015)
  male-en    LibriSpeech test-clean, utterance 2300-131720-0036 (0.40-4.40 s), CC BY 4.0
CC BY 4.0: https://creativecommons.org/licenses/by/4.0/ .
Only the three reference voices listed above are included in this delivery.
Other voices from older model packages are excluded from the Demo and example catalogue.
